# Loggy Web App

Aplicación web oficial de **Loggy** (Películas, Series y Libros).

## Características principales

- **Sincronización en tiempo real**: Conectada a Supabase (`profiles`, `cloud_reviews`, `review_likes`) para compartir la misma biblioteca, calificaciones y reseñas que la app móvil (Android e iOS).
- **Diario cultural personal**: Registro de películas, series y libros con calificaciones de 0.5 a 5.0 estrellas, notas personales y fechas de completado.
- **Buscador global**: Integración con TMDb para películas y series, y OpenLibrary para libros.
- **Comunidad y Spoiler Shield**: Reseñas de la comunidad con filtro inteligente contra destripes y sistema de «me gusta».
- **Estadísticas culturales**: Gráficos de distribución de notas y desglose por formato.
- **Bilingüe**: Soporte para español e inglés (regla de Sentence Case en toda la interfaz).
